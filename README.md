# The Totality of God — GitHub Pages

1. Extract this ZIP on your computer.
2. Upload the extracted files and the assets folder into the top level of your GitHub repository. Do not upload the ZIP itself.
3. In Settings > Pages, choose Deploy from a branch, select main and / (root), then Save.

index.html, app.js, style.css, and assets/ must remain together.
No build tools or API keys are needed. Passage popups use locally stored KJV text.

The assets folder contains the cover, diagrams, full study content, Bible text, and the downloadable Word study.
